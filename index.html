Selected research

Questions I have investigated.

Financial networks

Financial Mathematical Model Based on Network Entropy

Built international ETF networks with the Diebold–Yilmaz Spillover Index and measured systemic complexity using von Neumann entropy. The resulting entropy–spillover framework examines how network centralisation changes during periods of stress.

R · Python · Network analysis

Multi-asset structure

Structural Clustering of Correlation Matrices

Analysed 28 asset-class correlation matrices to understand cryptocurrency’s position in a multi-asset universe. Applied spectral clustering, k-medoids, Louvain modularity optimisation, and the Quotient Affine-invariant Metric.

MATLAB · Spectral clustering · QAM

Applied data science

Crop Phenotypic Data Standardisation

Used RGB ratio analysis and piecewise regression on 102 rice cultivars to identify growth stages from red–green channel dynamics, contributing to a peer-reviewed study and trait-clustering analysis.

Python · MATLAB · Image-based phenotyping
